# Task 01 — Project bootstrap

## Goal
Create the Spring Boot application skeleton and local development documentation.

## Scope
- Java 21, Maven, Spring Boot 3.x
- Web, validation, Spring Data JPA, SQL Server JDBC driver, Flyway, Springdoc OpenAPI
- Base package and application entry point
- `application.yml` or `.properties` with environment-driven configuration
- `ddl-auto=validate`, `open-in-view=false`
- `.gitignore`, `.dockerignore`, `.env.example`, README skeleton

## Acceptance criteria
- Maven wrapper included if possible.
- App compiles.
- No real secrets committed.
- No PostgreSQL driver or syntax.
- Configuration documents required environment variables.
